# \# ИИ-Агент: Помощник по привычкам

# 

# Консольный прототип ИИ-агента для формирования полезных привычек, отслеживания ежедневного прогресса и ведения статистики серий (`streak`).

# 

# \## Полный технологический стек

# 

# \- \*\*Язык программирования:\*\* Python 3.10+

# \- \*\*Среда выполнения:\*\* интерпретатор CPython

# \- \*\*Среда разработки (IDE):\*\* Visual Studio Code

# \- \*\*Менеджер зависимостей:\*\* `pip`

# \- \*\*Виртуальное окружение:\*\* модуль `venv`

# \- \*\*Библиотеки:\*\* стандартная библиотека Python (`sys`, `typing`)

# \- \*\*Средство хранения данных:\*\* структуры данных в оперативной памяти (In-Memory словарь в классе `HabitStorage`)

# \- \*\*Отладчик:\*\* встроенный отладчик VS Code (`Python Debugger` / `debugpy`) и стандартный модуль `pdb`

# \- \*\*Линтер:\*\* `flake8`

# \- \*\*Форматтер:\*\* `black`

# 

# \## Подготовка окружения и запуск

# 

# 1\. Клонировать репозиторий и перейти в папку проекта:

# &#x20;  ```bash

# &#x20;  git clone \[https://github.com/Ilya-design-sys/ai-agent.git](https://github.com/Ilya-design-sys/ai-agent.git)

# &#x20;  cd ai-agent

# &#x20;  ```

# 

# 2\. Создать и активировать виртуальное окружение:

# &#x20;  ```

# 

# 4\. Запустить приложение:

# &#x20;  ```bash

# &#x20;  python -m src.main

# &#x20;  ```

# 

# \## Назначение команд и штатное завершение

# 

# \- `add <название> <дней>` — добавить новую привычку с указанием цели в днях.

# \- `list` — показать список всех привычек, количество выполненных дней и текущую серию (`streak`).

# \- `done <id>` — отметить привычку с указанным `ID` выполненной за сегодня.

# \- `help` — вывести справочную информацию о командах.

# \- `exit` — штатно завершить работу приложения (также поддерживается выход по `Ctrl+C` / `EOF`).

# 

# \## Способ хранения данных

# 

# Состояние приложения хранится в оперативной памяти процесса в экземпляре класса `HabitStorage` (модуль `src/storage.py`) в виде словаря записей. Каждая запись содержит уникальный идентификатор `id`, название привычки `name`, целевое количество дней `target\_days`, счётчик выполнений `completed\_days` и текущую серию `streak`. В течение одного запуска состояние сохраняется и изменяется между командами; после завершения программы данные сбрасываются.

# \## Примеры диалога с приложением

# 

# \### Пример 1: Основной сценарий (добавление, отметка выполнения и просмотр прогресса)

# ```text

# agent> add Пить 2 литра воды 30

# Привычка 'Пить 2 литра воды' успешно добавлена с ID: 1 (цель: 30 дн.).

# agent> add Чтение книги 21

# Привычка 'Чтение книги' успешно добавлена с ID: 2 (цель: 21 дн.).

# agent> done 1

# Отлично! Привычка 'Пить 2 литра воды' выполнена. Текущая серия: 1 дн.

# agent> list

# 

# Ваши текущие привычки:

# \[1] Пить 2 литра воды | Выполнено: 1/30 дн. | Серия (streak): 1 дн.

# \[2] Чтение книги | Выполнено: 0/21 дн. | Серия (streak): 0 дн.

# ```

# \# ИИ-Агент: Помощник по учёбе

# 

# \*\*Назначение:\*\* Телеграм-агент для помощи студентам в управлении задачами и дедлайнами.

# \*\*Язык программирования:\*\* `Python`

# 

# \## Планируемые возможности:

# \* Добавление новых заданий с указанием дедлайна

# \* Просмотр списка задач на текущую неделю

# \* Отметка заданий как выполненных

# 

# \## Примеры запросов и результатов:

# \* \*\*Запрос:\*\* «Добавь лабораторную по ЭВМ на пятницу»

# &#x20; \* \*\*Ожидаемый результат:\*\* Агент сохранит задачу и ответит: «Задача успешно добавлена».

# \* \*\*Запрос:\*\* «Что нужно сделать на этой неделе?»

# &#x20; \* \*\*Ожидаемый результат:\*\* Агент выведет список всех актуальных задач.

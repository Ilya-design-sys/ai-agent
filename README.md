# ИИ-Агент: Помощник по привычкам

**Назначение:** Телеграм-агент для формирования полезных привычек, отслеживания ежедневного прогресса и построения мотивационной истории.
**Язык программирования:** `Python`

## Планируемые возможности:
* Добавление новых полезных привычек с указанием частоты и времени напоминаний
* Отметка ежедневного выполнения привычек и ведение статистики серий (streak)
* Отображение истории успехов и прогресса за выбранный период времени
* Фильтрация учебных задач по выбранному предмету

## Примеры запросов и результатов:
* **Запрос:** «Добавь привычку "пить 2 литра воды в день" ежедневно»
  * **Ожидаемый результат:** Агент создаст новую привычку в системе, настроит ежедневное напоминание и ответит: «Привычка успешно добавлена».
* **Запрос:** «Отметь, что я сегодня почитал книгу»
  * **Ожидаемый результат:** Агент обновит статус привычки на сегодняшний день, увеличит счетчик текущей серии и пришлет текущий прогресс.

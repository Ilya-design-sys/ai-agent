# ИИ-Агент: Помощник по привычкам

Консольный ИИ-агент для формирования полезных привычек, отслеживания ежедневного прогресса с учётом дат, сохранения состояния между запусками и ведения статистики серий (`streak`).

## Полный технологический стек

- **Язык программирования:** Python 3.10+
- **Среда выполнения:** интерпретатор CPython
- **Среда разработки (IDE):** Visual Studio Code
- **Менеджер зависимостей:** `pip`
- **Виртуальное окружение:** модуль `venv`
- **Библиотеки:** стандартная библиотека Python (`os`, `sys`, `json`, `pathlib`, `typing`, `datetime`)
- **Средство хранения данных:** локальный JSON-файл (`data/habits.json`), управляемый классом `HabitStorage`
- **Тестирование и покрытие:** `pytest`, `pytest-cov`
- **Линтер:** `flake8`
- **Форматтер:** `black`

## Подготовка окружения и запуск

1. Клонировать репозиторий и перейти в папку проекта:
   ```bash
   git clone [https://github.com/Ilya-design-sys/ai-agent.git](https://github.com/Ilya-design-sys/ai-agent.git)
   cd ai-agent
   ```

2. Создать и активировать виртуальное окружение:
   ```bash
   python -m venv venv
   # Для Windows (Git Bash):
   source venv/Scripts/activate
   # Для Linux / macOS:
   source venv/bin/activate
   ```

3. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```

4. Запустить приложение:
   ```bash
   python -m src.main
   ```

## Назначение команд и штатное завершение

- `add <название> <дней>` — добавить новую привычку с указанием цели в днях (`<дней>` — целое положительное число).
- `list` — показать список всех привычек, количество выполненных дней, текущую серию (`streak`) и дату последней отметки.
- `done <id>` — отметить привычку с указанным целым положительным `ID` выполненной за сегодня (принимает ровно один аргумент). Повторная отметка в тот же день не увеличивает число выполненных дней и серию.
- `help` — вывести справочную информацию о командах.
- `exit` — штатно завершить работу приложения (также поддерживается выход по `Ctrl+C` / `EOF`).

## Хранение состояния и момент сохранения

Состояние агента хранится на диске в формате JSON (по умолчанию в файле `data/habits.json`). Путь к файлу можно переопределить через переменную окружения `HABIT_STORAGE_PATH`. Файл с локальными данными исключён из Git через `.gitignore`.

Каждая запись в файле содержит поля `id`, `name`, `target_days`, `completed_days`, `streak` и `last_completed_date` (в формате ISO `YYYY-MM-DD` или `null`).

- **Восстановление состояния:** происходит автоматически при запуске приложения (в конструкторе `HabitStorage`). Если файл отсутствует (первый запуск), агент начинает работу с пустого состояния. При повреждении файла или ошибке чтения выводится сообщение об ошибке, и приложение продолжает работу с пустым состоянием.
- **Момент сохранения:** состояние записывается в JSON-файл сразу после каждой изменяющей операции (`add` и `done`), поэтому данные сохраняются даже при неожиданном завершении программы. При некорректном пользовательском вводе состояние не изменяется и не перезаписывается.

При выполнении `done <id>` за текущую дату (`date.today()`):
- повторный вызов в тот же день не засчитывается повторно;
- если прошлый зачёт был вчера (`last_completed_date == today - 1 день`), серия `streak` увеличивается на `1`;
- если был пропуск дней (`last_completed_date < today - 1 день`), серия `streak` сбрасывается до `1`;
- при первом зачёте серия устанавливается равной `1`.

## Автоматическое тестирование и покрытие кода

Тесты находятся в папке `tests/` и изолированы от пользовательских данных с помощью фикстуры `tmp_path`.

```bash
# Запуск всех автоматических тестов:
pytest

# Измерение покрытия строк (без учёта консольного интерфейса src/main.py):
pytest --cov=src.storage --cov=src.agent --cov-report=term-missing
```

## Проверки качества кода

Для форматирования и статического анализа кода используются `black` и `flake8`:

```bash
# Применение форматирования кода:
black src/ tests/

# Проверка соответствия форматированию:
black --check src/ tests/

# Проверка кода линтером:
flake8 src/ tests/
```
